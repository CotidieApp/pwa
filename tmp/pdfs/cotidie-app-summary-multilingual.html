What it is Cotidie es una app católica de oración y lectura espiritual, hecha con Next.js + Capacitor y publicada como PWA / Android.

Who it's for Católicos que quieren una rutina diaria de oración en el teléfono.

What it does
  • Biblioteca única de Devociones, Plan de Vida y Oraciones.
  • Rosario y Via Crucis en modos inmersivos.
  • EPUB del Nuevo Testamento con índice, búsqueda, marcadores y subrayados.
  • EPUBs personales guardados localmente en el dispositivo.
  • Oraciones, devociones, cartas y 4 planes personalizados.
  • Temporizador, recordatorios diarios y acciones rápidas en notificaciones.
  • Santo/frase del día, calendario de checks, estadísticas y Cotidie Annuum.
How it works
  • page.tsx carga splash + MainApp; MainApp cambia entre inicio, categorías, oración, ajustes y lectores.
  • SettingsContext reúne catálogo, stats, recordatorios, santos, temas y planes; persiste con IndexedDB (persistence.ts) + localStorage.
  • Capacitor + Android (MainActivity, receivers, widgets) manejan imports, acciones de notificación, recuperación WebView y widgets del santo.
How to run
  • npm install
  • npm run dev
  • Abre la URL local que imprima Next. Guía detallada / comando Android nativo: Not found in repo.

What it is Cotidie is a Catholic prayer and spiritual reading app built with Next.js + Capacitor and shipped as a PWA / Android app.

Who it's for Catholics who want a daily prayer routine on a phone.

What it does
  • One library for Devotions, Daily Plan, and Prayers.
  • Immersive Rosary and Way of the Cross modes.
  • New Testament EPUB reader with TOC, search, bookmarks, and highlights.
  • Personal EPUB uploads stored locally on the device.
  • User prayers, devotions, letters, and 4 custom plans.
  • Timer, daily reminders, and notification quick actions.
  • Saint/quote of the day, check calendar, stats, and Cotidie Annuum recap.
How it works
  • page.tsx loads splash + MainApp; MainApp switches home/category/prayer/settings/reader views.
  • SettingsContext joins catalog, stats, reminders, saints, themes, and plans; persists with IndexedDB (persistence.ts) + localStorage.
  • Capacitor + Android (MainActivity, receivers, widgets) handle imports, notification actions, WebView recovery, and saint widgets.
How to run
  • npm install
  • npm run dev
  • Open the local URL printed by Next. Detailed onboarding / Android native run command: Not found in repo.
